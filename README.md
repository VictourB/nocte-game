# Nocte


A Zelda II inspired side-scrolling engine focusing on high/low stance combat mechanics.

## Controls
* **Arrow Keys**: Move and Jump (UP)
* **Down Arrow**: Crouch (Low Stance)
* **Z Key**: Attack (Sword Thrust)
* **ESC**: Pause Game

## Current Features
- **Stance System**: Player and enemies can switch between High and Low stances.
- **Dynamic Hitboxes**: Shields only protect the active stance; sword thrusts must target the "gap."
- **Physics**: Gravity and floor collision with delta-time synchronization.
- **Knockback**: Tactical recoil when hitting shields or taking damage.
